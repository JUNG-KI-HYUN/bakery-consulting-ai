## MVP 목적

베이커리 예비창업자가 후보 점포를 계약하기 전에, 내부 상담 담당자가 다음 항목을 체계적으로 검토할 수 있도록 지원하는 웹 기반 상담 도구를 제공한다.

- 입지 및 임대차 조건 검토
- 시설·장비·인허가 리스크 점검
- 도면 기반 매장세팅 가능성 검토
- 손익분기점 추정
- mock AI 진단을 통한 4단계 최종 판단
- 고객용 리포트 생성 및 인쇄

본 MVP는 **내부 상담 보조 도구**이며, 창업 성공·매출·수익·권리금 회수를 보장하지 않는다. 모든 수치는 추정치 또는 참고값으로 제공된다.

## 구현된 기능 목록

### 1. 대시보드 (`/`)
- 전체 상담 건수, 진단 진행 중, 리포트 생성 완료, 조건부 추천·보류/위험 점포 수 요약 카드
- 상담 목록·상담 등록 화면 바로가기

### 2. 상담 목록 (`/consultations`)
- 등록된 상담 건 목록 표시
- 샘플 데이터 1건 포함 (서울 성동구 성수동 후보지 A)
- 샘플 데이터임을 명시하는 라벨 표시

### 3. 상담 등록 (`/consultations/new`)
- **상담 정보**: 고객명, 연락처, 창업예산, 희망지역, 창업경험, 희망 매장형태, 상담 메모
- **후보 점포**: 주소, 보증금, 월세, 관리비, 권리금, 전용면적, 층수, 전면 길이, 출입구 위치, 간판 노출, 주차, 기존 업종, 계약기간, 업종 제한, 원상복구 범위, 특약 필요사항
- **시설·장비 체크**: 전기 용량·증설, 급배수, 배기, 천장고, 화장실, 소방, 기둥 위치, 장비 반입·배치 가능성, 도면/현장사진 확인 여부
- **손익분기점**: 객단가, 방문객, 매출, 비용 항목 입력 및 실시간 추정 계산
- 임시 저장 및 mock AI 진단 실행

### 4. 상담 상세·진단 결과 (`/consultations/[id]`)
- 후보 점포 요약, 핵심 리스크, 입지·임대차·시설·도면·손익분기·마케팅 분석
- 최종 판단 4단계 표시 (추천 / 조건부 추천 / 보류 / 위험)
- 계약 전 확인 질문 목록

### 5. 고객용 리포트 (`/reports/[id]`)
- 문서형 리포트 미리보기
- 표지, 분석 섹션, 전문가 확인 필요 고지 포함
- 브라우저 `window.print()` 기반 PDF 출력

### 6. API 엔드포인트
- `GET/POST /api/consultations` — 상담 목록 조회·저장
- `GET /api/consultations/[id]` — 상담 상세 조회
- `POST /api/consultations/[id]/diagnose` — mock AI 진단 실행

### 7. 진단 로직 (mock)
- 손익분기점 계산 (`calculateBreakEven.ts`)
- 리스크 점수 기반 4단계 판단 (`calculateRisk.ts`)
- 진단 내러티브 생성 (`reportNarrative.ts`)

## 지원금 신청서용 요약문

> **AI 기반 베이커리 창업 점포진단 및 오픈 마케팅 지원 솔루션(프레임원 베이커리 창업진단 AI)**은 베이커리 예비창업자의 후보 점포를 계약 전에 체계적으로 검토하기 위한 내부 상담용 웹 MVP이다. 상담 담당자는 고객 정보, 후보 점포 임대차 조건, 시설·장비 체크리스트, 손익분기 추정값을 입력하면, 규칙 기반 mock AI 진단 로직이 입지·임대차·시설·도면·손익분기·마케팅 관점의 분석 결과와 4단계 최종 판단(추천/조건부 추천/보류/위험)을 제공한다. 진단 결과는 고객용 리포트로 출력 가능하며, 법률·세무·인허가·위생·소방·전기·배기·급배수 등은 전문가 확인이 필요함을 명시한다. 본 솔루션은 창업 성공, 매출, 수익, 권리금 회수를 보장하지 않으며, 모든 수치는 추정치 또는 참고값으로 제공된다. 2차 개발에서는 실제 AI API, 서울시 상권 API, PPTX 리포트 생성 기능을 연동할 예정이다.

## 면책 및 주의사항

- 본 솔루션은 **창업 성공을 보장하지 않는다**.
- 매출, 수익, 권리금 회수 기간은 **추정치 또는 참고값**이며, 실제 결과와 다를 수 있다.
- 법률, 세무, 인허가, 위생, 소방, 전기, 배기, 급배수 관련 사항은 **반드시 해당 분야 전문가의 확인**이 필요하다.
- AI 진단 결과는 계약 가능 여부를 단정하지 않으며, 최종 의사결정은 상담 담당자 및 예비창업자의 판단에 따른다.
