# 프레임원 베이커리 창업진단 AI — 진단 프로토콜

## 개요

본 문서는 1차 MVP에서 구현된 진단 흐름과 판단 기준을 정의한다. 현재 단계에서는 외부 AI API 없이 **규칙 기반 mock 진단 함수**(`mockAiDiagnosis`)를 사용하며, 2차 개발에서 실제 AI API로 대체할 수 있도록 모듈화되어 있다.

---

## 전체 흐름

```
[입력] → [분석] → [검토] → [리포트 생성]
```

| 단계 | 설명 | 담당 모듈 |
|------|------|-----------|
| 입력 | 상담·점포·시설·손익 정보 수집 | 폼 컴포넌트, API |
| 분석 | 손익분기 계산, 리스크 점수 산출 | `calculateBreakEven`, `calculateRisk` |
| 검토 | 4단계 최종 판단, 내러티브 생성 | `mockAiDiagnosis`, `reportNarrative` |
| 리포트 생성 | 고객용 문서 출력 | `DiagnosisReportDocument`, `PrintButton` |

## 3. 시설·장비 체크

베이커리 운영에 필요한 시설·인프라·장비 반입 가능성을 점검한다.

| 항목 | 판단 값 |
|------|---------|
| 전기 용량 / 전기 증설 가능 여부 | 가능 / 불확실 / 불가 |
| 급배수 / 배기 가능 여부 | 가능 / 불확실 / 불가 |
| 천장고 / 화장실 / 소방 확인 여부 | 텍스트·체크 |
| 기둥 위치 | 텍스트 |
| 오븐·믹서·발효기·냉장고·쇼케이스 반입·배치 가능성 | 가능 / 불확실 / 불가 |

## 4. 손익분기점 계산

입력된 매출·비용 항목을 바탕으로 추정 손익분기점을 산출한다. 모든 결과는 **추정치 또는 참고값**으로 표시된다.

### 입력 항목

예상 객단가, 일 방문객, 일매출, 월매출, 원재료비율, 인건비, 월세, 관리비, 카드수수료율, 배달수수료율, 광고비, 기타 고정비, 권리금

### 계산식 (`calculateBreakEven.ts`)

| 지표 | 계산식 |
|------|--------|
| 월세 부담률 | 월세 ÷ 예상 월매출 × 100 |
| 총 고정비 | 월세 + 관리비 + 인건비 + 광고비 + 기타 고정비 |
| 변동비율 | 원재료비율 + 카드수수료율 + 배달수수료율 |
| 손익분기 매출 | 총 고정비 ÷ (1 − 변동비율) |
| 권리금 회수 예상기간 | 권리금 ÷ 예상 월순이익 |

**화면**: `/consultations/new` — `BreakEvenForm`

## 5. mock AI 진단

입력 데이터를 종합하여 진단 결과를 생성한다. 현재는 외부 AI API 없이 규칙 기반 로직을 사용한다.

### 처리 순서 (`mockAiDiagnosis.ts`)

1. `calculateBreakEven` — 손익분기점 계산
2. `calculateRisk` — 리스크 점수 산출 및 4단계 판단
3. `buildNarrative` — 섹션별 분석 문구 생성

### 생성되는 분석 섹션

- 후보 점포 요약
- 핵심 리스크
- 입지 분석
- 임대차 조건 분석
- 시설·인허가 리스크
- 도면 기반 매장세팅 가능성
- 손익분기점 분석
- 오픈 후 마케팅 가능성
- 최종 판단
- 계약 전 확인 질문

**화면**: `/consultations/[id]` — `DiagnosisResultView`

## 6. 최종 판단 4단계

`calculateRisk.ts`의 리스크 점수 기반으로 다음 4단계 중 하나를 반환한다.

| 판단 | 조건 (리스크 점수) |
|------|-------------------|
| **추천** | 점수 0~1. 핵심 조건이 전반적으로 양호 |
| **조건부 추천** | 점수 2~4. 일부 협의 가능 항목 존재 |
| **보류** | 점수 5~6. 중대 리스크 다수 |
| **위험** | 점수 7 이상. 계약 전 재검토 강력 권고 |

### 주요 판단 기준

| 조건 | 가중 점수 | 판단 영향 |
|------|-----------|-----------|
| 제조형 매장 + 배기 불가/불확실 | +3 | 위험 또는 보류 |
| 전기 증설 불확실 또는 불가 | +2 | 보류 |
| 월세 부담률 15% 초과 | +2 | 보류 또는 위험 |
| 제조공간 확보 불가/불확실 | +2 | 보류 또는 위험 |
| 도면/현장사진 미확인 | +1 | 조건부 추천 이하 |

### 판단 원칙

- 상권이 양호해도 전기, 배기, 급배수, 장비 반입, 제조공간 문제가 크면 **보류 또는 위험**으로 판단한다.
- 도면 기반 매장세팅 결과는 최종 판단에 **반드시 반영**한다.
- 본 판단은 AI 보조 진단 기반 **참고 의견**이며, 계약 가능 여부를 단정하지 않는다.

## 7. 고객용 리포트 생성

진단 결과를 문서형 리포트로 출력한다.

### 포함 항목

1. 표지
2. 후보 점포 요약
3. 핵심 리스크
4. 입지 분석
5. 임대차 조건 분석
6. 시설·장비 리스크
7. 도면 기반 매장세팅 검토
8. 손익분기점 분석
9. 오픈 후 3개월 마케팅 플랜
10. 최종 판단
11. 계약 전 확인 질문
12. 전문가 확인 필요 고지

### 출력 방식

- 화면 미리보기: `/reports/[id]`
- PDF 출력: 브라우저 `window.print()` + `app/bakery-report-print.css`
- PPTX 생성: 2차 기능 (미구현)

**화면**: `/reports/[id]` — `DiagnosisReportPreview`, `DiagnosisReportDocument`

## 8. 전문가 확인 필요 원칙

본 솔루션의 모든 진단 결과 및 리포트에는 다음 원칙이 적용된다.

| 분야 | 확인 필요 사항 |
|------|----------------|
| 법률 | 임대차 계약, 업종 제한, 특약 조항 |
| 세무 | 창업 비용, 감가상각, 부가세 |
| 인허가 | 식품위생, 영업신고 |
| 위생 | HACCP, 위생 관리 기준 |
| 소방 | 소방시설, 피난 동선 |
| 전기 | 용량, 증설 가능성, 배선 |
| 배기 | 환기 설비, 배기 덕트 |
| 급배수 | 배수관, 오수 처리 |

### 문구 원칙

- 창업 성공 보장 표현 **금지**
- 매출·수익·권리금 회수 보장 표현 **금지**
- 모든 수치는 **"추정"**, **"참고값"**, **"확인 필요"** 표현 사용
- AI가 계약 가능 여부를 **단정하지 않도록** 작성
- 리포트 하단에 전문가 확인 필요 고지 **필수 포함**
