# 프레임원 베이커리 창업진단 AI — 신청서 첨부용 스크린샷 체크리스트

## 개요

지원금 신청서 또는 사업 설명 자료에 첨부할 화면 캡처 목록과 촬영 시 주의사항을 정리한다. 모든 캡처는 **샘플 데이터** 기준으로 진행하며, 실제 고객 정보·주소가 노출되지 않도록 한다.

### 캡처 환경

- 실행 명령: `npm run dev` 후 `http://localhost:3000` 접속
- 권장 해상도: 1920×1080 (데스크톱 기준)
- 브라우저: Chrome 또는 Edge 최신 버전

## 캡처 시 주의사항

### 필수 확인 사항

| 항목 | 확인 내용 |
|------|-----------|
| 샘플 데이터 표시 | "샘플 데이터" 라벨이 목록·상세 화면에 표시되는지 확인 |
| 실제 주소 오해 방지 | 주소 필드에 "샘플 데이터:" 접두어가 있는지 확인 |
| 추정치 표현 | 매출·수익·권리금 회수기간에 "추정" 또는 "참고값" 표현 확인 |
| 전문가 확인 고지 | 리포트 하단에 법률·세무·인허가 등 전문가 확인 필요 문구 확인 |
| 보장 표현 없음 | "성공 보장", "매출 보장", "회수 보장" 등 표현이 없는지 확인 |

### 캡처 품질

- 브라우저 주소창에 `localhost:3000`이 보이도록 캡처 (개발 환경임을 명시)
- 개발자 도구(F12)는 닫은 상태에서 캡처
- 스크롤이 필요한 화면은 섹션별로 분리 캡처
- 다크 모드가 아닌 라이트 모드(네이비+화이트톤) 기준 캡처

### 개인정보 보호

- 실제 고객명, 연락처, 주소를 입력하지 않는다
- 샘플 데이터(홍길동, 010-0000-0000)만 사용한다
- 캡처 후 개인정보 노출 여부를 재확인한다
