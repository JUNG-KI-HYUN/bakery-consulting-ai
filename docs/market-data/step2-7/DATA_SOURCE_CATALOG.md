## 2. 베이커리 분류 설계

| 분석대상 | 1차 공식 분류 | 보완 | 한계 |
|---|---|---|---|
| 제과점 | 서울 서비스업종/지방인허가 제과점영업 | 소진공 업종코드 | 제조·판매 형태가 다양 |
| 베이커리카페 | 제과점+커피·음료 후보 | 상호·업태·메뉴·현장검수 | 단일 공식 코드로 확정 어려움 |
| 카페 | 커피·음료 서비스업종 | 소진공 좌표 | 베이커리 경쟁 대체성은 모델별 차이 |
| 디저트 | 관련 소분류 후보군 | 메뉴·상호 규칙, 사람검수 | 오분류 위험 높음 |
| 프랜차이즈 | 서울 점포 데이터 프랜차이즈 수 | 공정위 가맹사업 정보 검토 | 브랜드별 점포 좌표 결합 별도 필요 |
| 대형 베이커리 | 공식 분류 없음 | 면적·좌석·주차·매출/현장 기준 | 임의 분류 기준을 공식사실로 표현 금지 |
| 개인 베이커리 | 전체-검증 프랜차이즈 후보 | 상호·사업자/현장 확인 | 가맹·직영·복수브랜드 구분 어려움 |

## 3. 산출 지표

- 현재 점포 수·면적당 밀도·생활인구 1만명당 밀도
- 4/8분기 신규·폐업 수와 순증감
- 생존점 업력 분포(원천이 허용하는 범위)
- 프랜차이즈 비중과 상위 브랜드 집중도
- 제과점·카페·디저트의 중첩 경쟁지수
- 주변 음식업 구성비와 시간대 수요
- 포화 후보 플래그: 수요 대비 고밀도 + 폐업 증가 + 매출 정체/감소가 동시에 관찰될 때

## 4. 법적·운영 체크

- 공개데이터 이용조건·공공누리 유형은 데이터셋별 페이지에서 배포 전 재확인한다.
- 지도/지오코딩 민간 API는 저장·캐시·재배포·상업 이용 조건을 계약 계정에서 확인한다.
- 네이버·카카오 플레이스 화면 무단 크롤링을 데이터 수집 기본방식으로 삼지 않는다.
- 상호·주소 등 사업체 데이터는 목적·보유기간·접근권한을 정하고 불필요한 개인정보를 저장하지 않는다.
- 호출제한은 공개 페이지에서 확정되지 않은 경우 `확인 필요`이며, 키 발급 후 1건→100건 샘플로 검증한다.
