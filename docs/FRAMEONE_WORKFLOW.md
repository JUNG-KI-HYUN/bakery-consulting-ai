# FRAMEONE 베이커리 점포개발 업무 흐름

Last updated: 2026-09-02

## 1. 문서 목적

이 문서는 FRAMEONE 베이커리 점포개발 시스템의 실제 업무 흐름을 정의한다.

프로그램은 단순 상권분석 도구가 아니라 아래 전체 흐름을 연결하는 실무형 점포개발 업무 시스템을 목표로 한다.

`매물 수집 → 후보점포 등록 → 사전분석 → 고객 브리핑 → 무료 리포트 → 현장출동 → 상세 현장조사 → 후보 비교 → 계약 전 검토 → 최종 상세 리포트 → 재조사`

개발 시 새로운 기능을 추가하기 전에 이 흐름 안에서 실제 업무시간을 줄이는 기능인지 먼저 판단한다.

---

## 2. 핵심 운영 원칙

### 2.1 한 번 입력한 데이터는 다시 입력하지 않는다

- 매물에서 가져온 주소를 지도에서 다시 입력하지 않는다.
- Kakao에서 수집한 경쟁점을 현장조사에서 다시 등록하지 않는다.
- 현장조사에서 찍은 사진을 리포트 작성 때 다시 업로드하지 않는다.
- 현장메모를 최종 리포트 작성 시 다시 타이핑하지 않는다.
- 고객 조건을 후보점포별로 반복 입력하지 않는다.

### 2.2 기존 데이터는 덮어쓰지 않는다

다음 정보는 변경 시 새 이력 또는 새 조사 회차로 저장한다.

- 보증금
- 월세
- 관리비
- 권리금
- 매물 상태
- 경쟁점
- 메뉴 및 가격
- 현장 유동
- 부동산 인터뷰
- 현장사진
- 시설상태
- 판단 결과

2~3개월 후 재조사 시 과거 조사내용을 유지하고 새로운 조사 회차를 생성한다.

### 2.3 데이터 출처를 구분한다

- Kakao 지도 / 장소검색
- 서울시 및 기타 공공데이터
- FRAMEONE 현장조사
- 직원 직접입력
- AI 분석 / 요약

서로 다른 출처를 하나의 확정 사실처럼 처리하지 않는다.

### 2.4 AI는 원본 데이터를 만들지 않는다

AI는 다음 업무에 사용한다.

- 데이터 비교
- 변화 요약
- 현장 음성메모 구조화
- 조사 누락 보조
- 고객 브리핑 문장 작성
- 최종 상세 리포트 초안 작성

AI가 매출, 경쟁점 수, 법률 가능 여부, 세무 판단, 인허가 가능 여부를 임의 생성하거나 확정하지 않는다.

# 3. 전체 업무 흐름

## STEP 1. 매물 수집

### 목적

온라인 또는 직원이 확보한 상가 매물을 빠르게 후보점포 DB에 등록한다.

### 입력 방식

1. Chrome Extension
2. 직원 직접입력
3. 중개업소 제공자료
4. 임대인 제공자료

### 기본 수집 항목

- 출처 사이트
- 원본 URL
- 매물번호
- 주소
- 보증금
- 월세
- 관리비
- 권리금
- 전용면적
- 층수
- 입주가능일
- 매물 설명
- 중개사무소
- 매물 사진
- 등록일
- 수집일

### 처리 원칙

매물정보 자동 추출 후 바로 확정 저장하지 않는다.

`자동 추출 → 직원 확인 → 후보점포 등록`

순서로 처리한다.

### 중복 확인

기존 후보점포와 주소, 위치, 면적, 매물조건 등이 유사하면 중복 가능성을 알려준다.

선택:

- 기존 후보점포에 새 매물 이력 추가
- 새로운 후보점포로 등록

---

## STEP 2. 후보점포 등록 및 상태관리

### 후보점포 주요 상태

- 신규
- 검토중
- 현장조사 예정
- 현장조사 완료
- 고객 브리핑
- 조건협의
- 보류
- 탈락
- 계약
- 매물 종료

### 매물 이력

동일 점포의 조건이 변경되면 과거 값을 보존한다.

예:

- 2026-09-02: 월세 380만원 / 권리금 3,000만원
- 2026-10-15: 월세 360만원 / 권리금 2,500만원
- 2026-12-05: 월세 350만원 / 권리금 2,000만원

---

## STEP 3. 사전 상권분석

### 목적

직원이 현장에 가기 전 후보점포 주변을 빠르게 파악한다.

### Kakao 지도

표시 항목:

- 후보점포
- 300m / 500m 반경
- 베이커리
- 제과점
- 카페
- 주요 생활편의시설
- 주차장
- 주요 배후시설

### 서울시 공식상권

Kakao Map 위에 서울시 공식상권 Polygon을 Overlay로 표시한다.

공식상권 클릭 시 기존 SALES / STORES 데이터를 연결한다.

### FRAMEONE 주요상권

FRAMEONE Market/Submarket/Node는 서울시 공식상권과 별개의 체계다.

FRAMEONE geometry를 임의 생성하지 않는다.

### 공공데이터 비교

향후 비교 대상:

- Kakao 장소검색
- 제과점 인허가 데이터
- 소상공인 상가업소 데이터
- 서울시 공식상권 데이터

카카오 검색 수와 공공데이터 수가 다르면 신규, 폐업, 누락, 업종분류 차이 가능성으로 표시하며 확정하지 않는다.

---

## STEP 4. 고객 브리핑

### 목적

고객 상담 및 내부 회의에서 후보점포의 핵심 내용을 빠르게 설명한다.

### UI 원칙

- 매우 단순하게 구성
- 지도 중심
- 기술용어 최소화
- 원본 API 필드, 내부 ID 기본 화면에서 숨김
- 숫자보다 의미를 먼저 표시

### 기본 구성

- 후보점포 요약
- Kakao 지도
- 300m / 500m
- 주변 베이커리 / 제과점 / 카페
- 서울시 공식상권
- 핵심 매출 / 점포 지표
- 주요 장점
- 핵심 리스크
- 추가 확인사항

---

## STEP 5. 무료 고객 리포트

### 목적

상담 고객에게 제공하는 1차 점포진단 자료다.

### 포함 항목

1. 후보점포 요약
2. 위치 지도
3. 주변 경쟁환경
4. 공식상권 기초자료
5. 핵심 장점
6. 핵심 위험
7. 계약 전 추가 확인사항

### 무료 리포트에서 제외할 상세정보

- 세부 경쟁점 현장조사 전체
- 부동산 인터뷰 전체
- 메뉴·가격 세부조사
- 전기·급배수·배기 상세진단
- 장비 세팅
- 도면 상세검토
- 임대차 특약 상세검토
- 손익분기점 상세계산
- 현장사진 전체
- 내부 조사 메모

---

## STEP 6. 현장출동 준비

### 목적

직원이 현장으로 출동하기 전에 무엇을 조사해야 하는지 자동으로 준비한다.

### 현장출동 준비팩

포함:

- 후보점포 기본정보
- 지도
- 300m / 500m 경쟁점
- 방문할 주요 베이커리·카페
- 주변 부동산 후보
- 주요 아파트 및 배후시설
- 주요 동선 후보
- 공식상권 기초정보
- 미확인 시설항목
- 촬영해야 할 사진
- 조사 체크리스트

### 오늘 꼭 확인할 항목

사전에 확인된 정보는 반복 질문하지 않는다.

미확인 항목을 우선 표시한다.

예:

- 전기 계약용량
- 배기 가능 여부
- 급배수 위치
- 장비 반입경로
- 전면 실측
- 권리금 포함시설
- 원상복구 범위

- 기존 인테리어
- 철거 필요
- 원상복구 예상

### 7.3 베이커리 시설

## STEP 8. 주변 부동산 조사

### 기본 기준

주변 공인중개사사무소 최소 5곳 방문을 기본으로 한다.

### 조사 항목

- 중개업소명
- 위치
- 방문일시
- 최근 임대료 분위기
- 최근 공실 분위기
- 권리금 수준
- 최근 계약사례
- 주요 유입 업종
- 베이커리 / 카페 수요 의견
- 상권 장단점
- 장기 공실 여부
- 특이사항

### 결과 처리

한 곳의 의견을 확정사실로 사용하지 않는다.

예:

- 임대료 상승 의견 3/5
- 공실 적음 의견 4/5
- 베이커리 적합 의견 3/5
- 권리금 부담 의견 4/5

## STEP 13. 조사 누락검사

현장을 떠나기 전 조사 누락 여부를 자동 확인한다.

예:

- 전기 계약용량 미확인
- 주변 부동산 인터뷰 4/5
- 경쟁점 메뉴판 사진 누락
- 배기 외부 토출 위치 사진 없음
- 특정 시간대 유동조사 미실시

### 결과

- 조사완료도
- 필수 미확인 항목
- 선택 미확인 항목

필수항목이 남아 있으면 현장 종료 전 재확인을 권장한다.

---

## STEP 14. 복귀 후 조사 정리

현장조사 내용을 직원이 다시 보고서로 작성하지 않도록 한다.

프로그램이 자동으로 다음 내용을 정리한다.

- 조사자
- 조사시간
- 부동산 방문 수
- 경쟁점 방문 수
- 유동조사 횟수
- 주요 시설상태
- 핵심 발견사항
- 미확인사항
- 촬영 사진 수

AI를 사용할 경우 원본 조사내용과 AI 요약을 구분한다.

## STEP 20. 재조사

2~3개월 후 동일 상권 또는 점포를 다시 방문할 수 있어야 한다.

### 원칙

과거 조사내용을 수정하지 않는다.

`현장조사 #1`
`현장조사 #2`

형태로 새 조사 회차를 생성한다.

### 재조사 모드

기존 조사 결과를 보여주고 각 항목을:

- 변화 없음
- 변경됨
- 재확인 필요

로 빠르게 입력할 수 있게 한다.

---

## STEP 21. 변화 비교

재조사 후 이전 데이터와 최신 데이터를 비교한다.

예:

- 월세 380 → 350만원
- 권리금 3,000 → 2,000만원
- 경쟁점 12 → 15곳
- 신규 베이커리 3곳
- 폐업 추정 1곳
- 공실 4 → 6곳
- 메뉴가격 변경
- 유동 변화
- 시설상태 변화

AI는 이 변화 데이터를 요약할 수 있지만 원본 수치를 변경하지 않는다.

---

## STEP 22. 고객 조건 및 매물 매칭

향후 고객별 조건을 저장하여 새 매물과 비교할 수 있게 한다.

예:

- 최대 월세
- 최대 권리금
- 희망 면적
- 1층 필수 여부
- 주차
- 제조형 여부
- 희망 지역
- 입주 시기

Chrome Extension 등으로 새 매물이 등록되면 조건이 유사한 고객 후보를 표시할 수 있다.
