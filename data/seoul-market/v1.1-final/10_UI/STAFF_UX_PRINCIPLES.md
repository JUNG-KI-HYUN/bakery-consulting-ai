# STAFF UX PRINCIPLES

1. 서울 → 자치구 → 주요상권 → 세부상권 → Node를 Windows 폴더처럼 탐색한다.
2. 기본 화면은 한글 상권명을 우선하고 공식코드·Market ID는 보조정보로 숨긴다.
3. 선택은 종속 드롭다운과 지도 클릭을 함께 지원한다.
4. 색상은 상태 표현에만 제한적으로 쓴다.
5. 모든 숫자에 출처·기준일·공간단위를 표시한다.
6. 확인된 공식 데이터 / 프레임원 분석 / 현장 확인 필요 / 오래된 데이터 / 미수집을 혼동하지 않게 배지로 구분한다.
7. 한 화면에는 핵심 지표만, 상세 수치는 탭 안에서 펼친다.
8. 현장조사 시작·기록 버튼을 눈에 띄게 둔다.
9. 상권 분석과 후보점포 계약판단을 별도 객체·화면으로 유지한다.
10. GIS·API 용어를 몰라도 사용할 수 있게 코드와 좌표계는 출처 탭에 둔다.
