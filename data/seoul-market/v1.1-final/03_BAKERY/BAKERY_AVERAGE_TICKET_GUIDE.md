# BAKERY AVERAGE TICKET GUIDE

| 구분 | 의미 | v1 처리 |
|---|---|---|
| 공식 객단가 | 카드사·리서치 등이 방법론과 함께 공개 | source_id·표본·기준시점이 있을 때만 |
| POS 실제 객단가 | 특정 점포 결제금액/결제건 | 점포·기간·환불·배달비 정의 필수 |
| 온라인 메뉴가격 관찰값 | 메뉴판·공식 채널의 개별가격 | 객단가로 변환 금지 |
| 프레임원 가정 | 손익 시나리오 입력 | 실적이 아니며 민감도 분석에만 사용 |

필수 구분값: `bakery / cafe / bakery_cafe / takeaway / dine_in / brunch / gift`

## v1 결과

상권별 공식 객단가는 일괄 확인하지 못했으므로 모두 `null`로 유지한다. 온라인 메뉴 조사 시 상호·지점·메뉴·옵션·관찰일·URL을 저장한다.
